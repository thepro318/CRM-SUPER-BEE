# Super BDC Base44 App Workspace

**Base44 App:** [Super BDC AI Sales Command Center](https://app.base44.com/apps/6ae9e5e4827f1f55e4d71eb2/editor/preview)

This is a Base44 app workspace created from the Super BDC design brief. It is a **separate** app from the GitHub prototype in this directory; neither codebase automatically syncs with the other.

## Boundaries

- Demo mode only
- Fictional lead records
- No live DealerSocket connection
- No text or email transmission
- No live customer data import or outbound automation

The linked app editor is where the application interface can be reviewed. For the GitHub source, see this directory's `index.html`, `premium.css`, `super-bdc.js`, and documentation.

## Integration milestone

A future production implementation requires an approved DealerSocket API connection, server-side user authorization, verified communications consent and opt-out processing, security review, tests, and deployment controls.
